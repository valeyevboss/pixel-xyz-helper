# Pixel XYZ Helper

> Многофункциональный хелпер для работы с координатами и расположением на SA-MP / Arizona RP.

---

## ?? Описание
**Pixel XYZ Helper** — инструмент для удобного и детального сбора точек на карте. Скрипт превращает процесс поиска нужных точек и записи координат в удобную и профессиональную работу.

## ? Ключевые возможности
* ?? **Категории и группы:** удобная сортировка сохраненных точек.
* ??? **Оверлей на экране:** наглядный вывод текущих координат в реальном времени с поддержкой свободного перемещения.
* ?? **Гибкая настройка:** детальная подгонка интерфейса под себя.
* ?? **Быстрое управление:** вызов функций через UI-меню и чат-команды.

---

## ?? Установка
1. Установите **MoonLoader** и библиотеку **mimgui**.
2. Поместите файл `PixelXYZ Helper.lua` в папку `moonloader`.
3. Папку `pixel_xyzhelper` из архива поместите в папку `moonloader/config`.

## ?? Активация
* **Клавиша:** `F2`
* **Команда в чате:** `/xyzmenu`
* **Помощь по всем командам:** `/xyzhelp`
